# Changelog [0.2.0]

All notable changes to this project will be documented in this file.

The format loosely follows Keep a Changelog.

---

## [0.2.0] - 2026-07-29

### Added

#### Tensor Arithmetic
- Tensor addition (`+`)
- Tensor subtraction (`-`)
- Tensor multiplication (`*`)
- Tensor division (`/`)
- Scalar arithmetic support

#### Matrix Operations
- Matrix multiplication (`@`)

#### Broadcasting
- NumPy-style broadcasting
- Automatic shape compatibility checking

#### Reduction Operations
- `sum()`
- `mean()`
- `max()`
- `min()`

#### Tensor Manipulation
- `flatten()`
- `squeeze()`
- `unsqueeze()`
- `repeat()`
- `tile()`
- `stack()`
- `concat()`
- `split()`

#### Indexing & Slicing
- Integer indexing
- Slice indexing
- Tuple indexing
- Basic advanced indexing

#### Testing
- Expanded unit test suite
- Total test count increased to **203 passing tests**

### Changed

- Improved tensor broadcasting implementation.
- Improved shape compatibility validation.
- Updated README documentation.

### Fixed

- Edge cases involving broadcasting.
- Indexing behaviour across tensor dimensions.
